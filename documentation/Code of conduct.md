# Code of Conduct

## 1. Purpose
This Code of Conduct establishes expectations for behavior in this project, aligning with widely accepted open-source standards and the spirit of the GNU Lesser General Public License v3.0 (LGPL-3.0). It applies to all participants and all project spaces.

## 2. Scope
This policy applies to all project spaces, including:
- Source code repositories, issues, and pull requests
- Discussions, documentation, and internal communications
- Community events or any collaboration channels related to the project

## 3. Our Standards
We are committed to a respectful, inclusive, and productive environment.

Expected behavior includes:
- Being respectful, considerate, and professional
- Listening and responding constructively
- Focusing on what is best for the project and community
- Respecting differing viewpoints and experiences
- Giving and gracefully accepting feedback
- Using welcoming and inclusive language

Unacceptable behavior includes:
- Harassment, discrimination, or hate speech
- Personal attacks, insults, or trolling
- Threats or encouragement of violence
- Publishing others’ private information without consent
- Disruptive conduct that harms collaboration

## 4. Open Source Values and LGPL-3.0 Alignment
This project is distributed under the LGPL-3.0. In support of its principles:
- We respect users’ freedoms to run, study, share, and modify the software.
- We expect contributors to honor license requirements, including proper attribution and preserving license notices where applicable.
- We do not tolerate misrepresentation of authorship or license terms.
- We encourage transparency in changes that affect interoperability, linking, or redistribution.

## 5. Reporting and Enforcement
If you experience or witness unacceptable behavior, please report it to the maintainers.

Maintainers will:
- Review reports fairly and promptly
- Maintain confidentiality to the extent possible
- Take appropriate action, which may include warnings, temporary restrictions, or removal from the project

## 6. Enforcement Guidelines
Maintainers may use the following guidelines to determine responses:
- **Correction**: A private, polite request to correct behavior
- **Warning**: A formal warning that a behavior must stop
- **Temporary restriction**: Limited participation for a defined period
- **Removal**: Permanent removal from project spaces

## 7. Attribution
This Code of Conduct is informed by common open-source community standards and adapted for this project’s LGPL-3.0 licensing context.
